# 📱 Mobile Accessories Store UI

A modern and responsive mobile accessories store website UI built using HTML5 and CSS3.

This project is a front-end demo created to showcase a clean and user-friendly interface for an online mobile accessories store.

> **Note:** This is a UI-only project. It does not include backend functionality, database integration, payment processing, or real product ordering.

## ✨ Features

- 🏠 Modern homepage
- 📱 Mobile accessories product showcase
- 🎧 Product cards
- 🔌 Product categories
- 🔍 Search bar UI
- 🛒 Shopping cart UI
- ❤️ Wishlist UI
- 🎨 Clean and modern design
- 📱 Responsive layout
- 💻 Desktop and mobile-friendly interface

## 🛍️ Product Categories

- 📱 Phone Cases
- 🔌 Chargers
- 🎧 Earphones & Headphones
- 🔋 Power Banks
- 🔗 USB Cables
- ⌚ Smart Accessories
- 🛡️ Screen Protectors
- 🔊 Bluetooth Speakers
